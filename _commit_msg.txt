fix: Chart Studio drawing tools — disable chart pan, implement click-to-draw flow

ROOT CAUSE:
- lightweight-charts captures mousedown for pan/drag before DrawingManager
- DrawingManager.setActiveTool() only stores state, doesn't create drawings on click
- handleClick() in the library does nothing when a tool is active

FIX:
- Disable chart pan/scale (handleScroll.pressedMouseMove, handleScale.axisPressedMouseMove)
  when a drawing tool is active, re-enable on cleanup
- Implement full click-to-draw flow:
  1. First click → place first anchor + create preview drawing
  2. Mouse move → update preview's second anchor (live preview)
  3. Second click → finalize drawing with both anchors
- Single-anchor tools (horizontal-line) finalize on first click
- Preview drawing removed if tool deselected mid-draw
- Uses correct v5 API: pressedMouseMove (not mousePressed), axisPressedMouseMove
