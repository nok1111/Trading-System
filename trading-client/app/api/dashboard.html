Binance API Keys

Configura tus API keys en el archivo .env (BROKER_API_KEY, BROKER_API_SECRET). Reinicia el contenedor para aplicar cambios.

📖 Cómo obtener tus API Keys de Binance (paso a paso)

1. Inicia sesión en Binance API Management

2. Click en "Create API" y selecciona System generated

3. Etiqueta la API (ej: "Alvora Trading")

4. Completa la verificación de seguridad (email + SMS/Google Authenticator)

5. En permisos, selecciona:

  • ✅ Enable Reading — necesario para ver saldo y posiciones
  • ✅ Enable Spot & Margin Trading — para ejecutar trades
  • ✅ Enable Futures — si usas futures (opcional)
  • ❌ NUNCA habilites "Enable Withdrawals"

6. En IP Access Restrictions, idealmente restringe a la IP del servidor (opcional pero recomendado)

7. Copia el API Key y API Secret y pégalos abajo

⚠️ IMPORTANTE: Guarda tu API Secret en un lugar seguro. Binance solo lo muestra una vez. Si lo pierdes, tendrás que crear una API nueva.
